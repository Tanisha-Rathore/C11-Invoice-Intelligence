# C11 – Invoice Intelligence

An AI-powered invoice processing and intelligence system built using React, FastAPI, Gemini Flash, and OCR technologies.

## Project Overview

C11 – Invoice Intelligence aims to automate invoice data extraction, validation, and analysis using Large Language Models (LLMs).

Users will be able to upload invoices in PDF format and receive structured information extracted from the documents.

## Technology Stack

- **Frontend:** React.js + Vite
- **Backend:** Python + FastAPI
- **LLM:** Google Gemini Flash
- **PDF Processing:** PyMuPDF
- **OCR:** RapidOCR
- **Data Validation:** Pydantic + JSON Schema
- **Database:** MongoDB (optional)

## Core Features

- Invoice PDF upload and processing
- Text extraction and OCR
- AI-powered structured data extraction
- Invoice data validation
- Five prompt-engineering experiments
- Evaluation dashboard
